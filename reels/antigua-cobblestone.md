# アンティグアの石畳はなぜ石畳なのか

リール台本と、裏取りしたファクト。

## 結論

**雨季の泥対策**。それ以上でも以下でもない。

土の道は雨季に沼になり、人も馬車も通れなくなる。そこで近くの川の丸石を敷いた。
ヨーロッパで先にあった舗装技術を、グアテマラ王国の首都だった街に持ち込んだもの。
石畳は排水と、街路や広場の清掃をやりやすくするためのインフラだった。

## よくある2つの説と、それが違う理由

### 説1「敵の足場を悪くする防御目的」→ ✗

- アンティグアには**城壁がない**。スペイン領で要塞化されたのはカルタヘナ、ハバナ、
  サンフアン、カンペチェ、ベラクルスといった**海賊が来る沿岸の港**。
- アンティグアは内陸のパンチョイ盆地、標高約1,500m。海からの脅威の想定外にある。
  「内陸に置くこと」自体が防御策で、壁も堀も要らなかった。
- そもそも石畳で困るのは、日常的にそこを通る自分たちの馬車と馬のほう。

### 説2「崩れた建物の瓦礫をそのまま敷いた」→ ✗（時系列が逆）

- 石畳は**都だった時代の舗装**。1773年のサンタ・マルタ地震より前の話で、
  瓦礫が出る前からそこにある。
- 地震のあとに起きたのは逆のこと。首都は1776年にヌエバ・グアテマラ・デ・ラ・アスンシオンへ
  移され、資材は**新首都へ運び出された**。住民が移転を拒んで残ろうとしたため、
  総督マルティン・デ・マヨルガは移転を確実にするため建物の取り壊しまで命じている。
  廃墟が今も残っているのは、運び切れなかった分。
- 材質が違う。石畳は**川で丸くなった石**（canto rodado／piedra bola）。
  崩れたのは焼成レンガ、日干し、切石、石灰モルタルで、形も種類も別物。

## 裏取りメモ

- 敷石は近隣河川の河床に自然に堆積した丸石。周囲が火山地帯なので、
  火山岩が川で削られて丸くなったもの。
- 交差点や道の中央には**大きめの石**が置かれている。通行を助けるため。
- 1543年のパンチョイ盆地での再建設のとき、新大陸で最初期の格子状（damero）の街区が引かれた。
- 現在の石畳は保存対象。1969年の議会令60-69号でアンティグア・グアテマラ市保護法ができ、
  CNPAG（アンティグア・グアテマラ保護国家評議会）が管理している。保存方針は街を
  ひとつの歴史的全体として扱い、石畳もその構成要素として保存される。
  1979年にユネスコ世界遺産。
- したがって**今踏んでいる石が全部260年前の同じ石とは限らない**。壊れれば同じ丸石で
  敷き直される、生きた保存。CNPAGは目地に talpetate と石灰を混ぜた「movitón」を推奨している。

### フック3案（冒頭4秒の差し替え用）

| 案 | セリフ | 狙い |

| B | 260年前に崩れた都で、唯一そのまま残ってるものがあります。 | 引きで作って足元に落とす。答えを最後まで隠せる |
| C | アンティグアの石畳、理由が地味すぎて逆に驚きました。 | 「地味」と先に言って期待値を下げ、落差で見せる |

A/B/C はどれも同じ本編につながるので、伸びなければフックだけ差し替えて再投稿できる。

### 撮り方メモ

- 冒頭4秒は**足元だけ**で引っぱる。顔も景色も出さない。「何の話？」で止まらせる。
- 42秒の「見て、この丸さ」は必ず手を入れて触る。丸い＝川石、という証拠がその一手で伝わる。
- 説①②はテロップに ✗ を出して即座に否定。テンポを落とさない。
- BGMは静かめ。石を触る音、足音を残す。

### ショットリスト（撮影順・場所ごとにまとめた実用版）

同じ場所で撮れるものを固めてある。上から順に回れば一周で足りる。

**① 石畳の通り（宿の前など、人の少ない道でよい）**

- [ ] 足元だけのウォーキング、縦、5秒 × 2テイク（フック用）
- [ ] 石畳の超アップ、丸さが分かる角度で3秒
- [ ] 石を手で触る／握るカット3秒 ← **必須**。丸い＝川石の証拠
- [ ] 歩き去る足元 → カメラを上げて通りの引き、6秒（締め用）

**② 少し引ける通り（サンタカタリナのアーチ周辺など）**

- [ ] アグア山が抜ける通りの引き、5秒
- [ ] 通りを横断するパン、5秒

**③ 廃墟（教会・修道院のどれか1か所で足りる）**

- [ ] 崩れた壁の引き、4秒
- [ ] アーチ、4秒
- [ ] 石材やレンガの断面のアップ、3秒 ← 石畳の丸石との対比に使う

**④ 雨のあと（別日でよい／なければ①のアップで代用）**

- [ ] 路面に水が流れているカット、4秒
- [ ] 石の隙間に溜まった水、3秒

**要らないもの**：ドローン、俯瞰、観光名所の全景。話が「街の紹介」に散る。
