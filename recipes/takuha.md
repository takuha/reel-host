## 書き方

上の1件をひな形として使う。項目は次の5つ。

| 項目 | 中身 |
| --- | --- |
| 見出し | 料理名 |
| 元動画 | 参考にした投稿の URL。クレジットのために必ず残す |
| 投稿者 | 元動画のアカウント名 |
| 追加日 | ここに足した日 |
| 状態 | `未書き起こし` → `書き起こし済` → `投稿済` |

`投稿済` にしたものは、`reel_post.sh publish takuha <動画> "<本文>"` まで通ったもの。
