## 引き継いだ人が順番にやること

1. 上の2つを青柳さんに確認する。ここが全部の前提
2. 〆を1つ選んで、台本8番のDのセリフを確定させる
3. PDFを印刷して撮影。**台本順ではなく役ごと**に撮る
   （面接官を全部 → 差し出す手 → 応募者A→B→C→D → インサート → 音だけ）。
   着替えの回数がそのまま撮影時間になるので、1つの役を着ているあいだに撮りきる
4. 編集。カット尻0.2秒、正解テロップだけ0.5秒長く、BGMは8番頭で止めて9番で戻す
5. `caption.txt` を確認して投稿

```sh
./reel_post.sh check   aoyagi
./reel_post.sh publish aoyagi ~/Movies/aoyagi_mensetsu.mp4 "$(cat daihon/caption.txt)"
```

6. 「応募」とコメントした人に応募フォームを DM で送る。文面と手順は
   `daihon/dm_aoyagi.md`。コメントから7日で送れなくなるので、投稿後は
   1日1回 `sweep` を回す

トークンは60日で切れる。`check` で弾かれたら `./reel_post.sh refresh aoyagi`。投稿が通れば
動画は自動で片付く（消し忘れも3日で `cleanup.sh` が拾う）。

## 変えないでほしいところ

- **Q1の正解を牛の答えに戻さない。** 青柳はあぐー豚。豚は中心まで火を通しきる必要があり、
  赤みが残ったものは出せない。「サッとくぐらせてピンクのまま」は牛の食べ方で、豚の店では
  一発アウト。Q1はこの取り違えをネタにしている。逆に書くと店の信用に関わる
- **「しゃぶしゃぶ」はひらがな。** テロップもキャプションも揃える
- **元ネタは構成だけ借りる。** 映像も音源も使わない。相手のオリジナル音源も使えないので
  BGMは自前で用意する
- **数字は盛らない。** 再生数も来客数も、測れていないものは出さない
- **1人5役の3つの決めごとを崩さない。** ①面接官と応募者を同じフレームに入れない
  ②面接官は左で右を見る・応募者は右で左を見る（この向きを最後まで変えない）
  ③面接官側は鍋が入る画、応募者側は椅子と壁だけ。どれか1つ崩れると会話に見えなくなる

## PDFの作り直し方

`daihon/daihon-print.html` を直してから、Chromium のヘッドレスで刷る。日本語フォント
（IPAexゴシックなど）が入っている環境で実行すること。入っていないと文字が豆腐になる。

```sh
chrome --headless --disable-gpu --no-sandbox --no-pdf-header-footer \
  --print-to-pdf=daihon/aoyagi_daihon.pdf daihon/daihon-print.html
```

macOS なら `chrome` は
`/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`。
A4・4ページに収まるよう調整済みなので、内容を足したらページ数を確認する。
