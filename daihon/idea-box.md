# アイデアボックス

思いついた企画を寝かせておく箱。撮れる状態になったものは台本に落として、出したら箱から抜く。
増やすことより、入っているものを1本ずつ出すことを優先する。

閲覧用ページ: https://claude.ai/code/artifact/53b99acd-6473-424f-ac7c-3273e7faec10

## この箱の使い方

- 表記は必ずひらがなで「しゃぶしゃぶ」。テロップもキャプションも揃える
- 数字は実測だけ。再生数も売上も、測れていないものは書かない
- 1本ずつ点火する。同時に3つ動かさない
- 新規制作より投稿が先。完成して止まっているものがあるうちは種を増やさない

## 【撮れる】しゃぶしゃぶの知識を間違えると即落とされるバイト面接

あぐー豚しゃぶしゃぶ青柳／60秒版・35秒版

店長のこうちゃんが鍋の前で面接官をやる。しゃぶしゃぶの質問に間違えた応募者はその場で不合格。
3人続けて落ちたあと、最後の1人が店の〆まで言い当てて採用される。

| | 質問 | 正解 |
| --- | --- | --- |
| Q1 | あぐー豚、何回しゃぶしゃぶする？ | 色が変わりきるまで。豚は火を通す |
| Q2 | 昆布出汁、沸騰させていい？ | 沸く直前で昆布を上げる |
| Q3 | 具材、どれから入れる？ | 白菜の芯・人参から。豆腐は後半 |
| オチ | うちの〆は？ | 答えられた1人だけ採用 → 肉を1枚食べさせて終わる |

**豚であって牛ではない。** 「サッとくぐらせてピンクのまま」は牛の食べ方で、あぐー豚の店では
一発アウト。Q1はこの取り違えをネタにしている。逆に書くと店の信用に関わるので反転させない。

**なぜこの店で効くか** — 10月1日オープンのバイト募集導線（応募フォーム → カレンダー予約 →
心斎橋事務所で面談）にそのまま着地する。面接そのものが題材なので、募集告知に見えずに
募集告知として働く。正解テロップは保存されやすく、客側にも刺さる。

**元ネタ** — SUSURU（@susuru_tv）「ラーメンの知識を間違えると即落とされるバイト面接」。
借りたのは構成だけで、映像・音源は使わない。オリジナル音源も使えないのでBGMは別で用意する。

**置き場** — `daihon/aoyagi-shabushabu-baito-mensetsu.md`（構成表・撮影香盤・テロップ・編集メモ）、
`daihon/caption.txt`（投稿本文）

**出すために埋まっていないもの**

- 〆が何か（うどん／雑炊／ラーメン／蕎麦／〆なし）。オチのセリフがここに乗る
- 応募フォームのURL。CTAの着地先
- 応募者役3人。店長役はこうちゃん本人が出ると強い

## 同じ型で増やせる種

面接フォーマットは「間違い → 即落ち → 正解テロップ」の反復なので、質問を差し替えるだけで
別の動画になる。1本目が当たったときだけ次を撮る。

| 種 | 中身 |
| --- | --- |
| その食べ方、赤いままです | 客側の間違いを同じテンポで。豚しゃぶで一番多い勘違いをそのまま題材にできる |
| 採用された人の初日 | 面接編の続き。受かった応募者Dが実際に働く。1本目を見た人が必ず見る |
| 抜き打ちテスト | 開店後、店長がスタッフに同じ質問をする。答えられなければその日は洗い場 |
| 利き出汁 | 昆布を引いた出汁と引いていない出汁を飲み分けさせる。店の仕込みの説明になる |
| あぐー豚クイズ | 産地・脂の融点・普通の豚との違い。知識テロップが強い回。客向けに振れる |
| 逆面接 | バイトが店長を面接する。落ちるのは店長。開店前の空気をやわらかく見せられる |

## 箱の外

しゃぶしゃぶ部の投稿セット5本は制作済みで、投稿だけが残っている。新しく撮るより先にそちらを出す。
