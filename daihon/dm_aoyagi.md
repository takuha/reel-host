# 青柳｜バイト面接リールの DM 文面と送り方

キャプションの締めは**「応募」とコメント → 応募フォームを DM で送る**、で確定している。
コメントが合図の言葉を兼ねるので、`sweep` は `--match 応募` で絞る。

文面の型は `dm_templates.md` の A（一通目でリンクを渡す）。バイト応募は
フォームを渡せば導線（フォーム → カレンダー予約 → 心斎橋事務所で面談）が
そのまま走るので、二通に分ける理由がない。質問がある人は返信してくるし、
返信が来れば24時間の窓が開いて `send` で返せる。

## 送る文面

`{{応募フォームURL}}` は青柳さん確認待ち（`hikitsugi.md` の「止まっている2つ」の2番）。
URL が入るまでは送らない。

```
あぐー豚しゃぶしゃぶ青柳です。
リールにコメントありがとうございます。

バイトの応募フォームはこちらです。
{{応募フォームURL}}

フォームから面談の日を選べます。場所は心斎橋の事務所です。
分からないことがあれば、このまま返信してください。
```

- 1行目の名乗りと「コメントありがとうございます」は削らない。
  名乗りの無いリンク付きDMは通報されやすい（`dm_templates.md` 参照）
- リンクはフォームの1つだけ。予約URLはフォーム側にあるので DM には入れない

## 送り方（手元のターミナルで。web セッションからは Graph API に出られない）

```sh
./reel_dm.sh check aoyagi                  # 権限の確認。落ちたらトークンを取り直す
./reel_dm.sh media aoyagi                  # 投稿一覧から面接リールの media-id を拾う
./reel_dm.sh comments aoyagi <media-id> --match 応募              # 誰が来ているか
./reel_dm.sh sweep aoyagi <media-id> "$(cat daihon/dm_aoyagi.txt)" --match 応募          # 下見
./reel_dm.sh sweep aoyagi <media-id> "$(cat daihon/dm_aoyagi.txt)" --match 応募 --send   # 送る
```

送る直前に、上の文面から URL を差し替えたものを `daihon/dm_aoyagi.txt` に置いて
`$(cat ...)` で渡す（改行と記号がシェルで壊れないように）。`sweep` は `--send` を
付けるまで送らない。宛先と本文を目で見てから付け直すこと。

- コメントから**7日**を過ぎた相手には送れない。投稿後は1日1回 `sweep` を回すと取りこぼさない
- 送信済みは台帳（`.dm_sent/aoyagi.log`）で自動で飛ぶ。同じ人に二度は行かない
- 返信が来た相手には `./reel_dm.sh threads aoyagi` → `./reel_dm.sh send aoyagi <igsid> "本文"`。
  相手の最後のメッセージから**24時間以内**だけ
