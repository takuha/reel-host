引き継いだ人が順番にやること

  1. 上の2つを青柳さんに確認する。ここが全部の前提
  2. 〆を1つ選んで、台本8番のDのセリフを確定させる（パターン表から選ぶだけ）
  3. PDFを印刷して撮影。台本順ではなく役ごとに撮る（面接官を全部 → 差し出す手 → 応募者A→B→C→D → インサート → 音だけ）。着替えの回数がそのまま撮影時間になるので、 1つの役を着ているあいだに撮りきる
  4. 編集。カット尻0.2秒、正解テロップだけ0.5秒長く、BGMは8番頭で止めて9番で戻す
  5. caption.txt を確認して投稿
./reel_post.sh check aoyagi ./reel_post.sh publish aoyagi ~/Movies/aoyagi_mensetsu.mp4 "$(cat daihon/caption.txt)"

トークンは60日で切れる。check で弾かれたら ./reel_post.sh refresh aoyagi。投稿が通れば動画は自動で片付く （消し忘れも3日で cleanup.sh が拾う）。

変えないでほしいところ
  • Q1の正解を牛の答えに戻さない。 青柳はあぐー豚。豚は中心まで火を通しきる必要があり、 赤みが残ったものは出せない。「サッとくぐらせてピンクのまま」は牛の食べ方で、豚の店では 一発アウト。Q1はこの取り違えをネタにしている。逆に書くと店の信用に関わる
  • 「しゃぶしゃぶ」はひらがな。 テロップもキャプションも揃える
  • 元ネタは構成だけ借りる。 映像も音源も使わない。相手のオリジナル音源も使えないので BGMは自前で用意する
  • 数字は盛らない。 再生数も来客数も、測れていないものは出さない
  • 1人5役の3つの決めごとを崩さない。 ①面接官と応募者を同じフレームに入れない ②面接官は左で右を見る・応募者は右で左を見る（この向きを最後まで変えない） ③面接官側は鍋が入る画、応募者側は椅子と壁だけ。どれか1つ崩れると会話に見えなくなる

ここまでの経緯

  • 元ネタのTikTokは本編を取得できなかったので、タイトルが示す構成（面接クイズ → 即不合格の反復 → 最後に採用）だけを借りて組み直した
  • 最初の稿は牛の前提で書いていた。青柳があぐー豚の店だと分かった時点でQ1を反転し、 「牛の感覚で答えて落ちる」形に組み替えている
  • オープン日・エリア・CTAが確定したので、テロップとキャプションを開店告知とバイト募集に寄せた。 当初あった〈エリア〉の穴はもうない
  • 出演をこうちゃん1人に変更した。応募者役を集める必要がなくなり、代わりに11番へ 「※面接官も応募者も、全部店長です」のオチを足している。段取りが減って、オチが1つ増えた
