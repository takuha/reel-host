# マルチゃん 1本目｜台本たたき台

自己紹介シリーズの1本目。エピソードは「結婚式場を借りて自分の誕生日パーティーを
開いた」の1本だけに絞る。経歴を並べる回ではなく、**マルチゃんという人物に興味を
持たせる**ための1本目。他のエピソードは `daihon/maruchan-profile.md` にまとめてあり、
2本目以降に小出しにする。

### オープニング

振り付けは別途プレビュー済み（①大きくマルを描く→②胸元で縮める→③OKサイン→
④回転→⑤決めポーズ）。腕は大きく伸ばす版で採用（サムネでの視認性を優先）。

### エピソード本体（台詞たたき台）

```
38歳、マルチゃんです。

自分の誕生日、結婚式場借りてやりました。
友達100人呼んで。

「なんでそこまでするの」ってよく聞かれるけど、
それがマルチゃんです。
```

台詞は仮。実際の口調・エピソードの盛り方はマルチゃん本人に確認してから
最終化する（`.claude/skills/reel-caption/` のルール通り、想像で埋めない）。

### 締め

次回予告にするか、プロフィール誘導にするかは撮影後に決める。1本目は
「認知を取る」目的が強いので、CTAを詰め込みすぎない。
