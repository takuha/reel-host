# 青柳｜Instagram に住所を載せる準備

2026-09-23 時点。**住所そのものはまだ受け取っていない。** 下の空欄を青柳さんに埋めて
もらえば、あとは手順どおりに入れるだけの状態にしてある。

**住所を推測で埋めないこと。** 「心斎橋」までは確定しているが、番地・建物名・階は
どこにも記録が無い。間違った住所を店のプロフィールに出すと、お客さんが迷う。

## 住所が載る場所は3つ

| 場所 | 何が出るか | どうやって入れるか |
| --- | --- | --- |
| ① プロフィールの住所 | プロフィールに住所と「経路」ボタン。タップで地図が開く | **アプリで手入力**（API では変えられない） |
| ② リールの位置情報タグ | 投稿の上に店名が出て、タップで地図と同じ場所の投稿一覧 | `reel_post.sh` が自動で付ける（`AOYAGI_LOCATION_ID`） |
| ③ 本文・自己紹介の文字 | テキストとしての住所 | `daihon/caption.txt` やプロフィール文に書く |

いちばん効くのは①。②は①の元になる Facebook ページの住所を使い回すので、先に①と
同じ住所を Facebook ページ側にも入れておく。

## 青柳さんに聞くこと

| # | 項目 | 回答 |
| --- | --- | --- |
| 1 | 載せるのは**店舗の住所**か**心斎橋事務所（面談場所）の住所**か | |
| 2 | 郵便番号 | |
| 3 | 住所（都道府県・市区町村・番地） | |
| 4 | 建物名・階 | |
| 5 | 表示する店名（`あぐー豚しゃぶしゃぶ青柳` でよいか） | |

1 と 6 は判断が要るので必ず聞く。バイト募集の段階では「面談は事務所、店は別」という
可能性があり、どちらを出すかで来る人の行き先が変わる。

## ① プロフィールに住所を入れる（アプリ）

プロアカウント（ビジネス）であることが前提。投稿APIの準備で既に切り替え済みのはず。

1. `@aoyagi` のプロフィール → **プロフィールを編集**
2. **連絡先オプション**（または「ビジネスの連絡先情報」）→ **ビジネスの住所**
3. 上の表の 2〜4 を入れて保存
4. プロフィール表示に戻り、住所が出ているか、タップして地図の位置が合っているか確認

プロフィール上の表示を消したいだけなら、同じ画面の「プロフィールに表示」をオフにする
（住所自体は残る）。

## ② リールに位置情報タグを付ける

タグに使えるのは「住所が入った Facebook ページ」の ID。Instagram と連携している店の
Facebook ページに、①と同じ住所を入れておけばそれがそのまま使える。

1. Facebook ページ（青柳）→ 設定 → ページ情報 → **住所** に同じ住所を入れて保存
2. 手元の PC で確認する（web セッションからは Graph API に出られない）

   ```sh
   ./reel_post.sh location aoyagi
   ```

   ```
   1234567890  あぐー豚しゃぶしゃぶ青柳  @aoyagi_shop
       住所: 542-XXXX 大阪府大阪市中央区心斎橋…
   ```

   「住所: 未設定」と出るページの ID は使えない（投稿時に弾かれる）。

3. 出てきた ID を `.env` に書く

   ```
   AOYAGI_LOCATION_ID=1234567890
   ```

以後、`reel_post.sh publish aoyagi …` / `post` / `next` は全部このタグ付きで投稿される。
1本だけ別の場所にしたいときは `--location <ページID>` で上書きできる。
`AOYAGI_LOCATION_ID` を空にすればタグなしに戻る。

## ③ 本文に入れる場合

リール本文 `daihon/caption.txt` は今「10月1日、大阪・心斎橋。」まで。住所を本文に
書くかどうかは①②が入ってから決めればいい（プロフィールと位置情報タグで地図まで
飛べるので、本文には「場所はプロフィールから」で足りることが多い）。
