# タクハ｜Claude Code リールシリーズ 台本

構成・方針は [plan.md](plan.md) を参照。以下は撮影・編集用の本番台本。

**読み方**
- 「音声」＝そのまま読む文。読点で区切る位置まで含めて書いてある
- 「テロップ」＝画面に焼く文字。音声とは別物。**音声の書き起こしにしない**
- 「画」＝そのカットで映すもの
- 「差し替え枠」＝元動画を見たうえで、具体エピソードに置き換えてよい箇所

想定尺は 5.5文字/秒（自然な速さ）で計算している。実測がオーバーしたら、
削るのは必ず**中盤**。冒頭3秒と最後の1行は削らない。

## R1｜AIが「提案」で止まる時代は終わった

**論点**: 実行革命 / ChatGPTとの違い　**尺**: 45秒　**役割**: シリーズの入口

| 時間 | 画 | テロップ | 音声 |
| --- | --- | --- | --- |
| 0:00-0:04 | 顔出し・アップ | **AIに"やっといて"が通る** | ChatGPTに聞いて、返ってきたコードを自分でコピペしてる人、まだそれやってるんですか。 |
| 0:04-0:12 | 画面収録（ターミナル起動） | 提案するAI → 実行するAI | Claude Code は、答えを教えてくれるAIじゃないです。手を動かすAIです。 |
| 0:12-0:24 | 画面収録（指示→ファイルが書き換わる） | 日本語で言うだけ | ターミナルで日本語で指示を出すと、自分でファイルを開いて、書き換えて、実行して、動くところまで確認します。こっちは何も貼り付けてない。 |
| 0:24-0:36 | 2分割（チャット画面 / ターミナル） | 敵じゃなくて、役割が違う | ChatGPTがダメって話じゃないです。相談する相手と、作業する相手は別ってだけ。考えを整理するのはチャット、実際に終わらせるのがこっち。 |
| 0:36-0:45 | 顔出し | この差、1回やると戻れない | 「教えてもらう」から「終わらせてもらう」に変わる。ここが一番デカい。1回やると、もう戻れないです。 |

**差し替え枠**: 0:12-0:24 のデモ内容。元動画のデモに寄せてもいいし、タクハの実務
（リール投稿の自動化など）に置き換えるとオリジナリティが出る。

**投稿本文**
```
「AIに聞く」から「AIにやってもらう」へ。

ChatGPTに聞いて、返ってきたものを自分でコピペする。
あの往復が丸ごと要らなくなるのがClaude Code。

日本語で指示すると、自分でファイルを開いて、
書き換えて、動くところまで確認してくれる。

相談する相手と、作業する相手は別。
そういう話です。

このシリーズ、全6本でやります。
```
`#claudecode #ai活用 #生成ai #ai初心者 #業務効率化`

## R2｜コードが書けない人ほど得をする

**論点**: 誰でも使えるツール　**尺**: 40秒　**役割**: 自分ごと化

| 時間 | 画 | テロップ | 音声 |
| --- | --- | --- | --- |
| 0:00-0:04 | 顔出し | **エンジニア向けだと思って避けてる人へ** | Claude Code、名前に Code って入ってるせいで、エンジニア用だと思って避けてる人、めちゃくちゃ多いです。 |
| 0:04-0:14 | 画面収録（黒い画面 → 日本語入力） | 打つのは日本語だけ | 確かに黒い画面で動きます。でも打つのは日本語です。コマンドを覚える必要はないし、コードを読める必要もない。 |
| 0:14-0:26 | 画面収録（コード以外の作業） | コードじゃない仕事も投げられる | しかも扱えるのはコードだけじゃない。ファイルを整理する、調べてまとめる、決まった手順を毎回同じようにやる。この辺、全部投げられます。 |
| 0:26-0:36 | 顔出し＋テロップ強調 | 書けない人のほうが伸びしろがデカい | むしろ書けない人のほうが伸びしろはデカいです。今まで人に頼むか諦めるかの二択だったところに、三つ目が増えるので。 |

Claude Code、名前で損してると思う。

今まで「人に頼む」か「諦める」の二択だった人ほど、

## R3｜AIを5体、同時に働かせる

**論点**: ５体のAIエージェントで実演　**尺**: 55秒　**役割**: 画で殴る／保存誘導あり

| 時間 | 画 | テロップ | 音声 |
| --- | --- | --- | --- |
| 0:00-0:05 | 画面収録（並列で走ってる画）を無音気味に見せる | **これ、AI5体が同時に動いてます** | これ、今AIが5体、同時に別々の作業をしてます。 |
| 0:05-0:15 | 同じ画面を寄りで | 1人に5個 → 5人に1個ずつ | 普通は1個ずつ順番に頼みますよね。Claude Code は、作業を分けて、別のAIに同時に持たせられます。 |
| 0:15-0:30 | 進捗が並ぶ画面 | 待ち時間が重なる＝速い | ここが効くのは、単に速いからじゃないです。**待ち時間が重なる**から速い。1個ずつだと5回待つところが、1回分の待ちで終わる。 |
| 0:30-0:42 | 顔出し | 向いてる仕事／向いてない仕事 | ただ何でも並列にすればいいわけじゃない。お互いに関係ない作業ほど向いてます。逆に、前の結果を見てから次を決めるやつは、素直に1個ずつのほうが速いです。 |
| 0:42-0:55 | 画面収録＋テロップ | 「調べる」を分けるのが一番ラク | 最初にやるなら「調べる」系を分けるのがおすすめ。バラバラに調べさせて、最後に自分でまとめる。これだけで体感が変わります。 |

**CTA**: 最後1.5秒にテロップ「やるときに見返す用｜保存」

**投稿本文**
```
AI、5体同時に動かせるの知ってました？

Claude Codeは作業を分けて、
別々のAIに同時に持たせられる。

速い理由は「たくさん動くから」じゃなくて、
待ち時間が重なるから。
1個ずつだと5回待つところが、1回で終わる。

向いてるのは、お互いに関係ない作業。
前の結果を見て次を決めるやつは、順番のほうが速い。

最初にやるなら「調べる」を分けるのがラクです。

やるとき用に保存しといてください。
```
`#claudecode #aiエージェント #ai活用 #業務効率化 #生産性向上`

## R4｜願望の質＝アウトプットの質

**論点**: 願望の質＝アウトプットの質 / 言語化が全て　**尺**: 40秒　**役割**: 引用される1本

| 時間 | 画 | テロップ | 音声 |
| --- | --- | --- | --- |
| 0:00-0:04 | 顔出し・寄り | **AIの出力が微妙なのは、AIのせいじゃない** | AIの出してくるものが微妙なとき、原因はAIじゃないです。だいたいこっちです。 |
| 0:04-0:14 | 2画面（雑な指示／具体的な指示と、その出力） | 欲しいものが曖昧＝出力も曖昧 | 「いい感じにして」と投げたら、いい感じの何かが返ってくる。当たり前です。**自分が何が欲しいか分かってない分だけ、出力もボヤける。** |
| 0:14-0:26 | 同じ2画面の下側を拡大 | 誰に / 何のため / どうなったら終わり | 変えるのは3つだけでいい。誰のためか、何のためにやるのか、どうなったら終わりか。この3行を足すだけで別物が返ってきます。 |
| 0:26-0:40 | 顔出し | 言語化の練習台としてのAI | だからこれ、AIを使う技術じゃなくて、自分が欲しいものを言葉にする技術なんですよ。逆に言うと、毎日それの練習をさせられてる。ここが伸びると、AI以外の仕事も普通に速くなります。 |

**差し替え枠**: 0:04-0:14 の対比サンプル。タクハの実務で実際に出した雑な指示と、
書き直した指示を並べるといちばん強い。作り物っぽくしないこと。

**投稿本文**
```
AIの出力が微妙なとき、原因はAIじゃない。

「いい感じにして」と投げたら、
いい感じの何かが返ってくる。当たり前です。

自分が何を欲しいか分かってない分だけ、
出力もボヤける。

足すのは3行でいい。
・誰のためか
・何のためにやるのか
・どうなったら終わりか

これ、AIを使う技術じゃなくて
欲しいものを言葉にする技術。

伸びるとAI以外の仕事も速くなります。
```
`#claudecode #ai活用 #プロンプト #言語化 #仕事術`

## R6｜経営者こそ、自分で触ったほうがいい

**論点**: 経営者こそ使うべき　**尺**: 60秒　**役割**: シリーズの締め

| 時間 | 画 | テロップ | 音声 |
| --- | --- | --- | --- |
| 0:00-0:05 | 顔出し | **「詳しい人に任せる」が一番損する** | AIツール、詳しい人に任せておけばいい。これ、経営者が一番やっちゃいけないやつです。 |
| 0:05-0:18 | 画面収録＋顔出しの重ね | 判断のスピードが上限になる | 理由はシンプルで、任せると、判断がぜんぶ人づてになるからです。「これできる？」を聞いて、返事を待って、また聞く。使えるかどうかの判断が、自分の手から離れる。 |
| 0:18-0:34 | 画面収録（自分で触っている画） | 触ると"できることの地図"が持てる | 1回自分で触ると、何ができて何ができないかの地図が持てます。この地図がないと、投資判断も採用も全部ふわっとする。逆にあると、報告を聞いた瞬間に妥当かどうか分かる。 |
| 0:34-0:50 | 顔出し | 手が空いてない人ほど効く | あと、経営者って一番「手が空いてない人」なんですよ。細かい作業を自分でやる時間がない。そこにこれが入ると、**やらずに諦めてた側**が動き出す。実際、効きが大きいのはそっちです。 |
| 0:50-1:00 | 顔出し・引き | 全部やらなくていい。1個でいい | 全部を自分でやる必要はないです。1個だけ、自分の手で最後まで通してみる。それで判断の精度が変わります。 |

**差し替え枠**: 0:34-0:50。「やらずに諦めてた作業」の実例をタクハの実務から1つ入れる。
抽象のままだと弱いので、具体を1個だけ差す。

**投稿本文**
```
AIツールを「詳しい人に任せる」。
経営者が一番やっちゃいけないやつだと思ってます。

任せると、判断が全部人づてになる。
できる？って聞いて、返事を待って、また聞く。
使えるかの判断が自分の手から離れる。

1回自分で触ると、
何ができて何ができないかの地図が持てる。
この地図がないと、投資も採用もふわっとする。

あと経営者は一番手が空いてない人だから、
「やらずに諦めてた側」が動き出すのがデカい。

全部やらなくていいです。
1個だけ、最後まで自分で通してみる。
```
`#claudecode #経営者 #ai活用 #dx #経営`
