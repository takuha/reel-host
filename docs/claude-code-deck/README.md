## 直し方

中身を変えるなら pptx を直接編集してよい。ただし**レイアウトごと作り直したいときは
`build.js` を直すほうが早い**。全ページが同じヘルパー（見出し・カード・ターミナル風の枠）
で組んであるので、色や余白を1か所変えれば全ページに効く。

```sh
npm install pptxgenjs
node build.js claude-code-summary.pptx
```

配色は `build.js` の先頭にまとまっている。`ACCENT` を差し替えればトーンが一括で変わる。

PDF を作り直すときは PowerPoint から書き出すのがいちばん確実。手元に PowerPoint が
ないなら LibreOffice でも出せる。

```sh
soffice --headless --convert-to pdf claude-code-summary.pptx
```

同梱の PDF は LibreOffice で書き出したもの。**日本語は Yu Gothic ではなく代替フォントで
出ている**ので、フォントまで揃えたいなら PowerPoint から書き出し直すこと。

## フォントについて

日本語は `Yu Gothic` を指定している。Windows と Office 付属のフォントなので大抵は
そのまま出るが、環境になければ PowerPoint 側で置き換えられる。**置き換わると文字幅が
変わってページによっては行が増える**ので、本番の環境で一度は通して確認すること。
